## 检索与恢复验证

- SQLite 与 Tantivy 数量不一致时，服务可从 SQLite 自动重建倒排索引。
- 中文文件名和正文通过单字/双字词项进入 Tantivy，查询“本地搜索”可命中对应文档。
- 断线根目录在全量扫描中不会误删旧文档；恢复后由健康检查触发补扫。
- 共享盘恢复后会重建操作系统监听，避免只补扫一次却丢失后续变化。
- EmbeddingRWKV Tiny 对每个文档生成代表向量和最多 4 个均匀片段向量；多文本 batch 的 WKV 状态计算并行执行，不可用时离线词项向量自动接管。
- 关键词模式不读取文档向量；监听事件只载入路径映射，避免 5 万文件下为普通关键词查询或单文件变化分配约 146 MB 向量内存。
