# 搜索 P0 优化与复测（2026-09-10）

## 本轮范围

落实弱相关候选过滤、Word 域代码清理两项。RWKV 模型、每文档最多四个语义片段、混合权重及界面分数含义保持不变。尚未实施全正文向量、重复结果折叠或重排模型。

- 长查询仅使用中文双字词和英文词召回，过滤部分常见问句词，不再用零散中文单字扩大召回。单个汉字查询仍可用。
- BM25 归一化前检查名称及命中片段的有效查询词覆盖。最少命中词数为 `max(min(2, N), min(4, ceil(N * 0.25)))`，N 为有效查询词数。空词集不通过。
- 无合格关键词命中、也无完整文件名包含匹配的候选，向量余弦相似度至少为 0.50；原有最终模式阈值继续生效。纯语义命中不强制包含关键词。
- 覆盖检查复用查询词，英文按词边界匹配，中文检查相邻字，避免为每个候选反复生成完整词项集合；同分结果按文档 ID 稳定排序。
- DOCX 使用带命名空间的 XML 解析，读取可见文字，跳过域指令，保留域显示结果、链接文字、段落边界及跨格式 run 的连续文字。普通正文中的 TOC 等词不会被盲目删除。
- 更新索引 profile 为 `rwkv7-tiny-corrected-unpadded-clean-word-v4`，自动重新解析和生成旧向量，源文件不改动。

## 验证方法

保留上一轮复核后的 36 条正向查询、4 条领域外查询和全部相关文档标签，仅更新清理后的语料指纹。测试中用户给桌面端添加了新目录，因此最终对比使用独立服务 `127.0.0.1:47654`，从索引备份恢复并重建原有国家电网目录，不移除或覆盖用户的新目录。

源文档仍为同一批 176 个文件，ID、路径、大小、修改时间完全一致。片段由 1,374 减为 1,287；DOCX 中匹配 `PAGEREF|HYPERLINK|_Toc[0-9]` 的片段由 124 降为 0。9 个已有失败文件仍未纳入评测。

第一版固定 25% 覆盖过滤了两条长问句，并引入重复分词开销。回归测试暴露问题后，增加长问句命中词数上限并优化覆盖计算，再运行最终测试；未修改答案标签。因此原有查询属于开发回归集，不是盲测。额外六条正向和四条负向查询在首次实际评测前固定，未按结果调整标签。
